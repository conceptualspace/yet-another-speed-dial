Yet Another Speed Dial 2
</h1>

**Unofficial maintained fork** of [Yet Another Speed Dial](https://github.com/conceptualspace/yet-another-speed-dial) by [Conceptualspace](https://github.com/conceptualspace). This project is based on that original work and is **not** the original store listing. Credits and copyright for the original code belong to Conceptualspace; this fork adds continued maintenance and new features (notably **nested folders**).

Store listings coming soon (Firefox / Chrome / Edge). Until published, load the unpacked `src/` folder in your browser’s extension developer mode.

A better new tab page and bookmark manager (speed dial) that respects your privacy, inspired by Opera.

- Automatically fetches site thumbnails using open graph standard
- Supports custom images, sorting, searching, and folders — **including nested folders**
- Uses the native bookmarks library so speed dials can be synced by the browser
- Supports limited importing from other browser extensions
- Available for Brave, Chrome, Edge, Firefox, Opera and Vivaldi
- Lightning fast UI: no ads, trackers, or bs

## Migration from the original

Speed dials are stored as normal browser bookmarks, so your existing Speed Dial folder and sites generally keep working. Enable only one new-tab extension at a time — if both the original and this fork are installed, they will conflict over the new tab page. Uninstall or disable the original if you switch to YASD2.
